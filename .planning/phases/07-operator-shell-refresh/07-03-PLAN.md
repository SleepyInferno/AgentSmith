# Plan 07-03: Shared PageTitle Component

## Goal

Create the `PageTitle` shared component and add it to the top of every protected route's page content, giving the operator a consistent orientation heading on every screen.

## Context

Decision D-11 introduces a shared page title component rendered at the top of the main stage for each route. Currently each page uses ad-hoc headings in different positions and styles. `PageTitle` replaces or wraps those ad-hoc patterns with a single layout-level contract so every protected route has a predictable heading at the same visual position.

This plan depends on Plans 07-01 and 07-02 because the shell layout is now stable (2-col grid, clean top bar) and the main stage is the correct rendering target. PageTitle sits at the top of each page's content, inside `<section className="agent-main-stage">`.

Decision this plan implements: D-11.

## Tasks

### Task 1: Create PageTitle component and CSS

Create `apps/web/src/components/PageTitle.tsx`:

```tsx
type PageTitleProps = {
  title: string;
  eyebrow?: string;
};

export function PageTitle({ title, eyebrow }: PageTitleProps) {
  return (
    <div className="agent-page-title">
      {eyebrow ? <p className="agent-page-title__eyebrow">{eyebrow}</p> : null}
      <h1 className="agent-page-title__heading">{title}</h1>
    </div>
  );
}
```

In `apps/web/src/styles.css`, add the `agent-page-title` CSS block after the `agent-topbar` block:

```css
.agent-page-title {
  padding: 20px 24px 0;
}

.agent-page-title__eyebrow {
  margin: 0 0 4px;
  color: var(--accent);
  text-transform: uppercase;
  letter-spacing: 0.14em;
  font-size: 0.75rem;
  font-weight: 700;
}

.agent-page-title__heading {
  margin: 0 0 20px;
  font-size: 1.5rem;
  font-weight: 700;
  color: var(--text-main);
  line-height: 1.2;
}
```

### Task 2: Add PageTitle to all protected route pages

For each route file below, add `import { PageTitle } from "../../components/PageTitle";` (adjust the relative path depth based on the file's location) and place `<PageTitle title="..." />` as the first element inside the page's top-level return container.

**Approach for each file:**
1. Read the file.
2. Add the PageTitle import.
3. Add `<PageTitle title="[route title from table above]" />` as the first child of the page's outermost return element (usually a `<section>`, `<main>`, or `<div>`).
4. If the page already has a prominent `<h1>` or `<h2>` that serves as the page title, remove it — PageTitle replaces it. If the existing heading is a sub-heading within page content (not a page title), leave it in place.
5. Do not change any other rendering logic, props, or state in the files.
