# Plan 07-02: Clean Top Bar and Sidebar Subtitle

## Goal

Replace the inline-styled header nav in `ProtectedLayout` with a clean `agent-topbar` top bar (brand + identity + sign-out only), migrate all header styles to CSS classes, rename the sidebar subtitle to `Agent-OS`, and update the two test files that referenced the removed nav.

## Context

`ProtectedLayout.tsx` currently renders a sticky header with three NavLinks (Dashboard, Connectors, Audit) using inline styles. This creates two competing navigation surfaces — the header nav and the sidebar. Decisions D-01 through D-04 consolidate navigation to the sidebar only; the top bar holds identity and session controls.

This plan depends on Plan 07-01 (BrowserToolbar and ReviewPanel removed, home route unified) because the `--topbar-height` CSS variable introduced here is consumed by the `agent-console` grid rule updated in 07-01. Plan 07-01 sets `min-height: calc(100vh - var(--topbar-height, 60px))` with a 60px fallback; this plan sets the authoritative value.

Decisions this plan implements: D-01, D-02, D-03, D-04.
