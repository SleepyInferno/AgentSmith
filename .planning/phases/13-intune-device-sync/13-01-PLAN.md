    **Step 4: Create `apps/api/src/modules/connectors/graph-helpers.ts`**
    Three exported functions:

    `buildGraphClient(prisma: PrismaClient, systemKey: Buffer): Promise<Client>`:
    - Reads IntegrationCredential row where key = "intune"
    - If no row found, throws Error("Intune credentials not configured")
    - Calls `decryptCredential(systemKey, row.encryptedValue, row.iv, row.authTag)`
    - Parses JSON as `{ tenantId: string; clientId: string; clientSecret: string }`
    - Creates `ClientSecretCredential(tenantId, clientId, clientSecret)` from `@azure/identity`
    - Creates `TokenCredentialAuthenticationProvider(credential, { scopes: ["https://graph.microsoft.com/.default"] })` from `@microsoft/microsoft-graph-client/authProviders/azureTokenCredentials/index.js` (per D-02, ESM import pitfall)
    - Returns `Client.initWithMiddleware({ authProvider })`

    `graphPageAll<T>(client: Client, path: string): Promise<T[]>`:
    - Type: `GraphPagedResponse<T> = { value: T[]; "@odata.nextLink"?: string }`
    - Calls `client.api(path).get()` for initial page
    - Pushes `current.value ?? []` into results array
    - While `current["@odata.nextLink"]` exists, calls `client.api(current["@odata.nextLink"]).get()` — passes FULL URL unchanged (per anti-pattern warning)
    - Returns flat `T[]` array

    `withRetry<T>(fn: () => Promise<T>, maxRetries = 3): Promise<T>`:
    - Attempts `fn()`
    - On catch: checks `(err as { statusCode?: number }).statusCode === 429`
    - If not 429 OR attempt >= maxRetries: rethrow
    - Reads `(err as { responseHeaders?: Record<string, string> }).responseHeaders?.["retry-after"]`
    - If present: sleep `parseInt(retryAfter, 10) * 1000` ms
    - If absent: sleep `Math.pow(2, attempt) * 2000` ms (2s, 4s, 8s)
    - Increment attempt, loop
