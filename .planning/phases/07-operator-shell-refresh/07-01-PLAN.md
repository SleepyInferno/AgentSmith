# Plan 07-01: Remove Dead Shell Components and Unify Layout

## Goal

Remove `BrowserToolbar` and `ReviewPanel` from the shell, unify the home route into the standard shell layout, update the CSS grid from 3-column to 2-column, and delete all dead CSS. Tests that assert removed elements are updated in the same pass.

## Context

The current `AppShell` in `apps/web/src/router.tsx` has two code paths: home route (`/`) renders a `mockup-app-shell` wrapper with no sidebar; all other routes render a 3-column console with `BrowserToolbar` at top, sidebar, main stage, and `ReviewPanel` on the right. This plan executes the three removals and the home route unification before any new content is added, leaving the app in a clean state with tests passing.

Decisions this plan implements: D-05 (remove BrowserToolbar), D-06 (unify home route), D-10 (remove ReviewPanel from shell).

## Files

Read these files before starting:

- `apps/web/src/router.tsx` — full file
- `apps/web/src/styles.css` — full file (find agent-browser, agent-console, agent-review-panel, mockup-app-shell blocks)
- `apps/web/tests/shell-navigation.spec.ts` — full file

### Task 2: Update CSS — 2-col grid and remove dead blocks

In `apps/web/src/styles.css`:

**Update `agent-console` grid:**

Find the `.agent-console` rule (the one with `grid-template-columns: 266px minmax(0, 1fr) 324px`). Change it to:

```css
.agent-console {
  display: grid;
  grid-template-columns: 266px minmax(0, 1fr);
  min-height: calc(100vh - var(--topbar-height, 60px));
  /* preserve any other existing properties on this rule */
}
```

The `--topbar-height` custom property defaults to `60px` (matches the `agent-topbar` header height added in Plan 07-02). The variable forward-references Plan 07-02's work cleanly.

**Remove these dead CSS blocks entirely** (the components they styled no longer exist):

- `.mockup-app-shell` block
- `.mockup-dashboard`, `.mockup-dashboard__frame`, `.mockup-dashboard__image`, `.mockup-dashboard__hotspots`, `.mockup-dashboard__hotspot`, `.mockup-dashboard__hotspot:focus-visible` blocks

- `.agent-review-panel` and all sub-rules (the full block including `__header`, `__close`, `__stack`, `__eyebrow`, `__label`, `__value`, `__body`, `__review-note`, `__seal`, `__seal-ring`, `__checkbox`, `__action`)
- Any `@media` rules that reference the removed classes (`agent-browser` responsive block, `agent-review-panel` responsive block)

Do not remove any other CSS. The `agent-shell`, `agent-sidebar`, `agent-main-stage`, and all breakpoint rules that affect those blocks must be preserved.

**Update responsive `agent-console` media queries:**

At the `@media (max-width: 1180px)` breakpoint, the existing rule likely sets the grid to 2 columns by collapsing the review panel column. After this plan, the console is always 2-col, so the 1180px `grid-template-columns` rule for `agent-console` becomes redundant — it can be removed or simplified to match the base rule. Keep the sidebar width adjustment at that breakpoint if it exists.
